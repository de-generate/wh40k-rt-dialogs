# Rogue Trader dialogs

Tools for exploring the dialogs of *Warhammer 40,000: Rogue Trader* (base game + DLC1–3).

| Project | What it does |
|---|---|
| [`wh40k-rt-dialog-extractor/`](wh40k-rt-dialog-extractor/) | Standalone Python tool: parses an exported blueprint dump into `dialogs.json` and renders readable scripts |
| [`wh40k-rt-dialog-explorer/`](wh40k-rt-dialog-explorer/) | Web app for searching and clicking through dialogs (in planning) |

The repository contains no game data. You need your own export of the game files (see the extractor's README).
